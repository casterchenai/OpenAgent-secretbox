# 远端固定入口阶段验收清单

适用场景：Hermes 安装在阿里云服务器，用户通过 Hermes Web UI、飞书或微信接收请求，
并通过 SecretBox 向服务器项目写入环境变量、证书和私密文件。

测试时只使用假密钥和测试证书。完成后删除测试文件和测试会话。

## 1. 一次部署，固定入口

- [ ] **只开放一次网络入口**
  - 操作：确认云安全组只开放现有 HTTPS `443`，连续创建三个 SecretBox 请求。
  - 预期：三个请求使用同一个门户域名；不需要新增端口或修改安全组。

- [ ] **服务只监听服务器本机**
  - 操作：检查 SecretBox Gateway 的监听地址和反向代理目标。
  - 预期：Gateway 监听 `127.0.0.1` 固定端口，公网只暴露 HTTPS 反向代理。

## 2. 聊天和 Agent 边界

- [ ] **聊天只出现固定门户地址**
  - 操作：让 Agent 在 Web UI、飞书或微信中创建一个请求。
  - 预期：消息可以包含固定门户地址和非敏感请求名称，但不包含 `/intake/`、
    `#token=`、浏览器会话 ID、密钥值或文件内容。

- [ ] **链接预览不会消费请求**
  - 操作：让聊天渠道生成门户链接预览，然后由用户正常打开门户。
  - 预期：预览访问只能看到登录页，待处理请求仍然有效。

- [ ] **Agent 结果保持脱敏**
  - 操作：提交含唯一测试字符串的环境变量和文件，再检查 MCP 返回、Agent 回复及日志。
  - 预期：仅出现名称、相对目标、动作和状态；唯一测试字符串与文件正文均不存在。

## 3. 用户登录和请求选择

- [ ] **未登录用户看不到请求**
  - 操作：使用无痕浏览器访问固定门户和已知请求入口。
  - 预期：只能看到登录页，无法查看请求元数据，也不会消耗请求。

- [ ] **错误访问密钥不会泄露信息**
  - 操作：输入错误 access key。
  - 预期：页面给出通用错误，不显示正确 key、请求数量、服务器路径或内部异常。

- [ ] **登录后可区分多个请求**
  - 操作：同时创建两个标题和目标不同的请求。
  - 预期：门户列出两个独立请求，可分别打开、取消或完成，不会串单。

## 4. 精准写入，不手工找目录

- [ ] **环境变量写入指定项目**
  - 操作：在表单中填写假环境变量并提交。
  - 预期：页面在提交前显示服务器项目、`.env.local` 和 merge-only 策略；提交后仅新增声明变量。

- [ ] **多层级文件写入准确**
  - 操作：上传假 PEM 到 `config/payment/certs/apiclient_key.pem` 等已授权深层目标。
  - 预期：用户无需浏览服务器目录；文件写入声明位置并应用 owner-only 权限。

- [ ] **未授权目标被阻止**
  - 操作：请求 allowlist 之外的路径或带 `..` 的路径。
  - 预期：在打开表单前失败，不能通过 Agent 参数扩大 allowlist。

- [ ] **已有值不会被覆盖**
  - 操作：目标中预先放置不同测试值，再提交同名变量或同路径文件。
  - 预期：返回 conflict/blocked，原内容保持不变且不会生成持久备份副本。

## 5. 生命周期和错误体验

- [ ] **页面明确提示单次提交**
  - 操作：打开待处理请求。
  - 预期：页面醒目说明请求只能提交一次、刷新和提交后的行为。

- [ ] **提交成功提示清晰**
  - 操作：完成一个无冲突请求。
  - 预期：页面明确显示已安全写入，可关闭页面；不回显输入值或文件正文。

- [ ] **提交后刷新不会重复写入**
  - 操作：成功后刷新并尝试后退。
  - 预期：显示已使用提示，不重新提交，也不再次创建文件。

- [ ] **过期和取消可区分**
  - 操作：分别等待短 TTL 过期和由 Agent 取消请求。
  - 预期：页面给出明确的“已过期”或“已取消”，并提示需要向 Agent 重新申请。

- [ ] **服务重启安全失效**
  - 操作：创建待处理请求后重启 Gateway。
  - 预期：内存请求与登录会话失效，旧页面不能继续提交，页面给出可理解提示。

## 6. 测试清理

- [ ] 删除所有测试 `.env` 项和测试证书文件。
- [ ] 撤销或删除测试用 access key，并确认真实凭据从未用于验收。
- [ ] 确认仓库、Agent 聊天、日志、截图和 shell 历史中没有测试提交值。
